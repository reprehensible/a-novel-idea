# Manuscript

One file per chapter: `chNNN-short-title.md` (e.g. `ch001-the-last-ferry.md`).
Zero-padded three-digit numbers so files sort correctly. Interludes:
`int-A-title.md` placed by outline order.

Files contain **prose only** — a chapter heading, the text, `* * *` scene
breaks. No notes, no metadata (that lives in `notes/` and `bible/plot/`).

Word counts: `wc -w manuscript/ch*.md` — update STATUS.md after each chapter.
