# Character Files

One file per significant character, named `firstname-lastname.md` (or single
name). Created in Phase 1, updated whenever a character grows on the page.

Minor named characters (innkeepers, guards, couriers) don't get files but DO
get a line in `../glossary.md` so names stay consistent.

## Template

```markdown
# Name

**Role:** (POV / major / supporting)
**First appears:** ch. —

## Essentials
Age, appearance (3–4 memorable specifics, reused for consistency), occupation.

## Voice
How they talk: rhythm, vocabulary, verbal habits. 2–3 sample lines.
How they think (colors their POV narration, if POV).

## Wants and fears
Surface want / deep want / greatest fear / the lie they believe.

## Secrets
What they're hiding, who knows, when the reader learns it (link promises.md).

## Arc
Where they start → pressure points → where they end. Per-act beats.

## How they fight / act under pressure
(Style, signature choices — action is character.)

## Relationships
One line per significant relationship, updated as they change.
```

Current state (injuries, location, knowledge) lives in `notes/continuity.md`,
NOT here — these files hold the durable design, not the moment-to-moment state.
